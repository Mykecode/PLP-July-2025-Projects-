Data Analysis Assignment 

Overview
This is a Python-based data analysis challenge that processes a sales dataset from a CSV file. It calculates total revenue, identifies the best-selling product (by quantity sold), and finds the day with the highest sales (by revenue).

Results are printed in a user-friendly format and saved to a text file. As a bonus, it includes a visualization of daily sales trends using Matplotlib.

The assignment demonstrates basic data manipulation with Pandas and simple plotting.

Features:
Load and parse sales data from sales_data.csv. The sale dataset is gotten from kaggle website.
Compute total revenue across all records.
Group data by product to find the top seller by quantity.
Group data by date to identify the highest sales day.
Generate and save a summary report to sales_summary.txt.

Bonus: Create a line plot of daily revenue trends, saved as daily_sales_trend.png.
