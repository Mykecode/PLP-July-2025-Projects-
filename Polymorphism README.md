Activity 2: Polymorphism Challenge
This project demonstrates Polymorphism in Object-Oriented Programming using Python.

Task
Create a program that includes animals or vehicles with the same action (like `move()`).
Each class should define the method differently.  
Example: Car.move() ----> "Driving". Plane.move() ----> "Flying "

Solution
I created a Vehicle base class and Train, Boat, Airplane and Car subclasses that override the move() method:

Car --> The Car is Driving smoothly.
AirPlane --> The airplane is Flying high.
Boat --> The boat is Sailing smoothly.
Train --> The train is running smoothly.

This shows how different objects can share the same method name but have different implementation.
