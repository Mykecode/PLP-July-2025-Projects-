Python File Operation
This is a Python program that read a user provided file and also add new content to the file and stores it in a new file.

Features
Takes file input from user, display it and also ask the user for new content to add to the file and store in a new file.

How It Works
1. The program asks the user to enter name of file to be read.
2. It displays the file if it exist.
3. It ask the user to enter new content to add to the file.
4. The program then adds the new content to the file and store it in a new file.
