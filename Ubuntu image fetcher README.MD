Ubuntu Image Fetcher:
This script downloads images from given URLs and saves them into a local directory named Downloaded.


Features:
1. Downloads images from multiple URLs.

2. Automatically creates a Downloaded directory if it doesn’t exist.

3. Handles errors gracefully with descriptive messages.

4. Assigns a default name if the image URL does not contain a filename


How It Works:
1. The user provides one or more image URLs (separated by commas).

2. The program fetches each image and saves it to the Downloaded folder.

3. If a URL is invalid or unreachable, an error message is shown.

4. Upon successful download, the user is notified with the save path.
